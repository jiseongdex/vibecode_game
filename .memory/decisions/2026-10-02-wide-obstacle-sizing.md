# Decisions: 가로형 장애물 겹침 완화

- Date: 2026-10-02
- Status: Confirmed

## D01. 조정할 이미지
- **Chosen**: 사탕 테마 `maze-candy-wall-02.png`, 얼음 테마 `maze-ice-wall-03.png`, 사막 테마 `maze-desert-wall-03.png`의 표시 크기를 줄인다. 숲 테마와 나머지 장애물 이미지는 기존 크기를 유지한다.
- **Rationale**: 사용자가 사탕·얼음·사막 테마를 지정했다. 실제 이미지를 확인하면 이 세 에셋의 그림이 가로로 길어 공통 `185%` 표시 규칙에서 옆 장애물을 더 많이 덮는다.

## D02. 크기 조정 방식
- **Chosen**: 위 세 에셋에만 셀 크기 대비 `135%`의 가로·세로 표시 크기를 적용한다. 나머지는 `185%`를 유지한다. 테마별 에셋 설정에 표시 배율을 두고 `MazeWall`이 CSS 변수로 읽도록 하여 이미지 경로를 조건문으로 검사하지 않는다.
- **Rationale**: 가로형 그림의 실제 폭은 원본 정사각 캔버스 대부분을 차지하므로 같은 `185%` 크기에서는 보통 장애물보다 크게 보인다. `135%`로 조정하면 그림의 가로폭이 약 한 타일보다 조금 큰 정도가 되어 이웃 장애물을 가리는 양이 줄어든다.

## D03. 유지할 게임 동작
- **Chosen**: 장애물 슬롯·미로 벽 데이터, 충돌 판정, `wallDepth` 앞뒤 순서, 이미지 비율과 에러 fallback을 유지한다. 단계별 테마에 영향을 주는 시각 조정만 검증한다. 맵틀 크기와 내부 시야 칸 수는 변경하지 않는다.
- **Rationale**: 문제는 장애물 그림의 시각적 겹침이며, 논리적 미로 구조나 저장 데이터의 문제가 아니다.
