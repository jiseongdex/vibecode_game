# Decisions: 장애물에 막힌 플레이어의 크기 안정화

- Date: 2026-10-01
- Status: Confirmed

## D01. 원인
- **Chosen**: 막힌 이동 시도에도 `MazeBoard`가 걷기 애니메이션을 요청해 `PlayerSprite`가 기본 PNG와 두 걷기 PNG를 반복 교체하는 것이 크기 출렁임의 원인이다.
- **Rationale**: 여자 탐험가 정면 PNG들은 모두 1254×1254이지만 알파가 있는 실제 그림 높이는 기본 1011px, 걷기 A 1033px, 걷기 B 1084px이다. 장애물 앞의 고정 위치에서 110ms 주기로 프레임을 바꾸면 크기 차이가 눈에 띈다.

## D02. 막힌 이동의 표시
- **Chosen**: 플레이어 좌표가 바뀌지 않은 입력에서는 걷기 프레임을 재생하지 않고, 현재 방향의 기본 이미지를 계속 표시한다. 막힌 방향으로 처음 돌아설 때의 기존 100ms 방향 전환 효과는 유지한다.
- **Rationale**: 연속 입력 중 캐릭터의 보이는 크기를 일정하게 유지하면서 방향 전환 피드백은 살린다.

## D03. 정상 이동과 범위
- **Chosen**: 실제로 한 칸 이동하면 현재의 걷기 프레임·이동 속도·카메라 추적을 유지한다. 키 반복 주기, 충돌 규칙, 플레이어 이미지 파일과 1.6칸 표시 크기, 구출 동물 동작은 변경하지 않는다.
- **Rationale**: 막힌 상황에만 발생하는 문제이므로 보드에서 이전·다음 플레이어 시각 격자 좌표를 비교해 애니메이션 여부를 결정할 수 있다.
