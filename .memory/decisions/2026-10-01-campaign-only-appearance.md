# Decisions: 단계 선택에서만 탐험가 설정

- Date: 2026-10-01
- Status: Confirmed (요청과 현재 화면 구조로 결정)

## D01. 선택기 위치
- **Chosen**: `PlayerAppearancePicker`를 `App`의 공통 영역에서 제거하고 `CampaignScreen`의 단계 선택 내용 안에 배치한다.
- **Rationale**: 현재 공통 영역에 있어 게임 시작 후에도 선택 버튼이 나타난다. 단계 선택 화면 안에 두면 게임 준비·플레이·일시정지·결과 화면에서는 설정할 수 없다.

## D02. 선택 값과 저장
- **Chosen**: `App`이 기존 `appearance` 상태와 `maze-rescue-game.appearance.v1` 저장을 계속 관리하고, 선택 값과 변경 함수를 `CampaignScreen`에 전달한다. 게임에는 선택된 값만 전달한다.
- **Rationale**: 단계 선택으로 돌아올 때와 새로고침 후에도 마지막 선택을 유지한다. 저장 형식 및 진행 세션 스키마를 바꿀 필요가 없다.

## D03. 플레이 도중 외형
- **Chosen**: 게임 화면에서는 탐험가 선택 UI를 제공하지 않는다. 단계 선택에서 정한 외형을 현재 게임과 바로 다음 단계에 사용하고, 단계 선택으로 돌아와서만 다시 변경할 수 있다.
- **Rationale**: 사용자가 지정한 변경 가능 범위를 단계 선택 페이지로 한정한다.
