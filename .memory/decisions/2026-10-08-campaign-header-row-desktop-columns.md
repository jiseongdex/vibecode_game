# Decisions: 제목 행과 데스크톱 랭킹·단계 배치 정리

- Date: 2026-10-08
- Status: Confirmed

## D01. 제목과 계정 배치
- **Chosen**: 데스크톱 단계 선택 화면의 상단에서 제목·기존 안내 문구를 왼쪽 묶음으로, 닉네임·로그아웃을 오른쪽 묶음으로 같은 행에 배치한다. 기존 모바일 탭 기준인 900px 이하에서는 내용을 잘리지 않게 두 묶음을 세로로 배치한다.
- **Rationale**: 사용자가 첨부한 데스크톱 화면은 제목과 계정이 서로 다른 행에 있다. 기존 제목·닉네임·로그아웃·초점 동작은 유지해야 한다.

## D02. 단계 진행 요약 문구
- **Chosen**: 단계 패널의 `완료 N/20단계 · 해금 N/20단계` 문구와 관련 렌더링·스타일만 제거한다. 단계 해금, 완료 판정, 단계별 최고 기록은 유지한다.
- **Rationale**: 요약 문구 삭제 요청은 진행 데이터 자체의 삭제가 아니다.

## D03. 랭킹과 단계의 데스크톱 배치
- **Chosen**: 901px 이상에서는 창 높이가 650px 이하라도 랭킹 왼쪽·단계 오른쪽의 1:1 열 배치를 유지한다. 낮은 창에서는 문서 스크롤로 내용에 접근한다. 900px 이하의 기존 단계 선택 기본 탭·랭킹 탭은 유지한다.
- **Rationale**: 현재 `(max-height: 650px)` 규칙이 넓지만 낮은 창을 세로 배치로 바꾸고 있다. 1440×900 무스크롤과 모바일 탭은 기존 검증 조건이다.

## D04. 작업 격리
- **Chosen**: 배포 Task의 기존 스테이징 파일과 실제 배포 포인터를 보존하고, 이 화면 수정만 별도 커밋한다.
- **Rationale**: Cloudflare·Microsoft 실사용 검증은 아직 진행 중이며 이번 요청과 독립적이다.
