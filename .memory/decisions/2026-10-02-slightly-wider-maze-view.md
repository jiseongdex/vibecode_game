# Decisions: 게임 내부 미로 시야 조금 확대

- Date: 2026-10-02
- Status: Confirmed

## D01. 보이는 맵 칸 수
- **Chosen**: 현재 약 `10.33×7`칸에서 약 `11.5×7.8`칸으로 시야를 넓힌다. 내부 viewport `1240×840` 기준 타일 크기를 `120px`에서 `108px`로 줄인다. 실제 보이는 칸 수는 `1240/108≈11.48`, `840/108≈7.78`이다.
- **Rationale**: 사용자가 제시된 선택지 중 타일을 약 10% 작게 하는 정도를 선택했다.

## D02. 맵틀과 카메라
- **Chosen**: 맵틀의 외형 비율과 반응형 배율은 그대로 둔다. 타일·플레이어·장애물·동물에 동일한 cell 크기와 sceneScale을 사용해 상대 비율을 유지한다. 카메라의 중심 추적과 맵 끝 경계는 새 타일 크기로 다시 계산하되 기존 공식은 유지한다.
- **Rationale**: 요청은 맵틀 크기가 아니라 맵틀 내부에서 보이는 미로 범위의 변경이다. 기존 배율 계산은 창 너비와 남는 높이에 맞춰 맵틀 전체를 조절한다.

## D03. 기존 기능과 검증
- **Chosen**: 게임 제목 숨김, 캠페인, 노트북 `1440×900px` 무스크롤 레이아웃, 모바일 전용 방향 버튼, 게임 상태·저장 데이터와 이미지 자산은 유지한다. 카메라 시작·중앙·끝 좌표, 0.5배/확대 배율, 플레이어/타일 비율, 노트북·모바일 실제 브라우저 시야를 검증한다.
- **Rationale**: 타일 크기가 바뀌면 기존 테스트의 픽셀 좌표와 타일 기대값이 달라지지만 게임 규칙이나 저장 좌표는 바뀌지 않는다.
