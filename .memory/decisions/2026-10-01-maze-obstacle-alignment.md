# Decisions: 미로 플레이어 및 장애물 정렬

- Date: 2026-10-01
- Status: Confirmed (recommended default adopted after no reply)

## D01. 장애물 앞 플레이어 이동
- **Chosen**: 기존 렌더 격자 칸 단위 이동과 충돌 판정을 유지한다. 캐릭터 그림만 해당 격자 칸의 중앙에 맞춰, 장애물 바로 옆 열린 칸에 섰을 때 자연스럽게 보이게 한다.
- **Rationale**: 이동 상태와 충돌 판정은 이미 장애물 옆의 열린 칸까지 허용한다. 현재 스프라이트 CSS 위치가 칸 중심보다 반 칸 위와 왼쪽으로 밀려 있어 화면 위치가 좌표와 다르게 보인다. 소단위 이동으로 게임 규칙을 바꿀 필요가 없다.

## D02. 연결된 장애물 렌더링
- **Chosen**: 연결된 벽 칸 경계에서 바닥색 틈이 보이지 않게 벽 이미지의 투명 여백과 타일 배경을 보정한다. 미로 벽 점유 및 무작위 이미지 변형은 유지한다.
- **Rationale**: 현재 각 벽 칸에 투명 여백을 가진 PNG를 개별 배치하고 타일 내부만 잘라 그려 인접한 이미지 사이로 바닥이 비쳐 보일 수 있다. 충돌 데이터 대신 시각 렌더링만 수정한다.

## D03. 플레이어 표시 순서와 벽 이미지 투명도
- **Chosen**: 플레이어를 벽 타일보다 위에 렌더링하고, 벽 타일의 불투명 단색 배경을 제거한다. PNG의 알파 영역에는 보드 바닥이 비치게 한다. 이 결정은 D02의 타일 배경 채움 방식을 대체한다.
- **Rationale**: `.obstacleTile`의 배경색이 투명 PNG 뒤를 채우고 `z-index: 7`인 벽 타일이 `z-index: 6`인 플레이어를 가린다. 플레이어 이동 좌표와 PNG 자체는 정상이다.
