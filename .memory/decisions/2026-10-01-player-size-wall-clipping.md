# Decisions: 플레이어 크기와 장애물 이미지 잘림

- Date: 2026-10-01
- Status: Confirmed (코드 확인 후 적용)

## D01. 플레이어 크기
- **Chosen**: 플레이어 표시 상자를 시각 격자 `1.4`칸에서 `1.6`칸으로 키운다. 상자의 왼쪽·위쪽을 시각 격자 위치에서 `0.3`칸 앞으로 옮겨 기존 격자 중심에 유지한다. 구출 동물 크기와 위치는 변경하지 않는다.
- **Rationale**: 현재 플레이어 상자 폭이 `1.4`칸이고 시작점은 `position - 0.2`칸이어서 중심이 `position + 0.5`칸이다. 폭만 늘리면 중심이 밀리므로 시작점을 `position - 0.3`칸으로 보정해야 한다.

## D02. 장애물 이미지 잘림
- **Chosen**: `.wallBlock`의 `185%` 크기는 유지하고, `.obstacleTile`의 `overflow: hidden`을 제거하여 이미지가 타일 경계 밖까지 자연스럽게 보이게 한다. 게임 화면 `.viewport`의 화면 경계 잘림은 유지한다.
- **Rationale**: 현재 장애물 PNG에는 넓은 투명 여백이 있어 이미지를 확대해 배치한다. 타일 자체의 `overflow: hidden`이 투명 여백 바깥의 장애물 실루엣까지 잘라 보이게 한다. 이미지를 다시 줄이면 연결된 장애물 사이 간격이 생길 수 있다.

## D03. 레이어와 게임 규칙
- **Chosen**: 플레이어·구출 동물이 장애물보다 위에 보이는 기존 레이어 순서와 장애물 PNG의 투명 배경을 유지한다. 이동·충돌·카메라·저장 형식은 변경하지 않는다.
- **Rationale**: 이번 문제는 스프라이트 상자와 CSS 클리핑에 한정된다. 장애물의 격자 점유 및 게임 상태를 바꿀 필요가 없다.
