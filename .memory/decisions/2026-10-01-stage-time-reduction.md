# Decisions: 단계별 제한 시간 단축

- Date: 2026-10-01
- Status: Confirmed

## D01. 단축 폭
- **Chosen**: 모든 단계의 기존 제한 시간을 약 20% 단축한다. 1단계는 122초에서 98초(1분 38초), 20단계는 755초에서 604초(10분 4초)로 조정한다.
- **Rationale**: 사용자가 제시된 20% 단축안을 선택했다. 기존 제한 시간이 너무 길다는 체감을 줄이면서, 단계별 차이는 유지한다.

## D02. 단계별 계산 방식
- **Chosen**: `src/game/stageConfig.ts`의 `getTimeLimitSeconds(stage)`에서 기존 미로 크기와 구출 동물 수 기반 시간을 계산한 다음 0.8배로 줄이고 정수 초로 올림한다. 기존 최소 제한 시간 90초와 유효 단계 범위 1~20을 유지한다.
- **Rationale**: 기존 공식이 단계별 난도에 맞춰 시간을 늘리고 있으므로 한곳에서 배율만 적용하면 모든 단계가 일관되게 단축된다. UI와 게임 상태가 같은 `timeLimitSeconds`를 사용한다.

## D03. 적용 범위
- **Chosen**: 새로 시작하거나 재시도하는 단계에 변경된 제한 시간을 적용한다. 게임의 초당 카운트, 일시정지, 승패 판정, HUD 시간 형식, 미로 크기, 구출 동물 수는 변경하지 않는다.
- **Rationale**: `createGameState`가 단계 설정의 `timeLimitSeconds`로 남은 시간을 초기화하고 재시도 시 상태를 다시 생성한다. 제한 시간 값 외의 타이머 동작을 바꿀 필요가 없다.
