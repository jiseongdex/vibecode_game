# Decisions: 타이틀 하단 사용자 정보 배치

- Date: 2026-10-06
- Status: Confirmed

## D01. 사용자 정보 위치와 표시 항목
- **Chosen**: 로그인 후 타이틀 헤더가 보이는 화면에서 소개 문구 아래 오른쪽에 계정 표시 이름과 로그아웃 버튼만 둔다. 기존 별도 계정 카드와 이름 뒤의 `님`은 제거한다.
- **Rationale**: 요청한 위치와 항목을 그대로 반영한다. 현재 세션 모델에는 별도 닉네임 필드가 없고 `account.user.displayName: string`이 화면 표시 이름이다.

## D02. 진행 새로고침
- **Chosen**: 사용자가 선택한 대로 `진행 새로고침` 버튼과 이 버튼만을 위한 App 상태·오류 UI를 삭제한다.
- **Rationale**: 헤더의 사용자 정보에는 두 항목만 남긴다. 로그인 시 서버 진행 기록을 초기값으로 받고, 단계 완료 시 서버 응답으로 기록을 갱신하는 기존 동작은 유지한다.

## D03. 게임 진행 화면
- **Chosen**: 타이틀 헤더가 숨겨지는 실제 게임 진행 중에는 사용자 정보 줄도 함께 숨긴다. 캠페인 화면으로 돌아오면 다시 보인다.
- **Rationale**: 사용자 정보의 유일한 배치 장소를 요청한 타이틀 영역으로 제한한다.

## D04. 진행 중 배포 작업
- **Chosen**: 현재 P03 배포 작업의 포인터를 임시로 보관하고 이 UI 작업 완료 후 되돌린다. 이미 준비된 배포 파일은 건드리지 않는다.
- **Rationale**: 사용자 요청을 처리하면서 진행 중인 배포 작업의 문맥과 별도 변경 사항을 보존한다.
