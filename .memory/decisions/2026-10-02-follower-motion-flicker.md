# Decision: 빠른 동물 이동의 깜박임 개선

## 요구와 확인

- 사용자는 따라오는 동물이 빠르게 움직일 때 깜박이는 것처럼 보여 플레이어처럼 자연스럽게 움직이길 원한다.
- `PlayerSprite`는 `translate`의 120ms 전환을 쓰고 방향 이미지를 미리 로드하며 `<img>` 요소를 유지한다.
- `RescueSprite`는 방향 이미지의 `src`를 React `key`로 써 방향 변경마다 `<img>`를 교체한다. 실패 처리만 있고 새 이미지가 로드될 때 숨김을 되돌리는 처리가 없다.
- `.followerSprite`는 `top`·`left`를 전환한다. 빠른 연속 이동에서는 이 좌표 변경과 이미지 재생성이 함께 일어난다.

## 결정

- 구출한 동물은 플레이어와 동일하게 위치를 `translate`로 이동하고 120ms 선형 전환을 유지한다. 구출 전 동물은 제자리에 표시한다.
- 방향 이미지 네 장을 동물별로 미리 로드한다. 방향이 바뀌어도 같은 `<img>` 요소의 `src`만 갱신하고, 로드 성공 시 오류로 숨겨진 이미지를 다시 보인다.
- 동물 종류·순서·방향·철장·플레이어 애니메이션과 저장 데이터는 유지한다.
- 빠른 연속 방향 전환과 이미지 로드 실패 후 회복을 DOM 테스트로 검증한다. 육안 평가가 필요한 움직임의 질감은 테스트의 한계로 기록한다.
