# 결정 문서: 미로 구출 게임

- 날짜: 2026-09-29
- 상태: 확정

## D01. 프론트엔드 기술 스택
- **선택**: Vite + React + TypeScript
- **근거**: 현재 저장소가 초기 상태이며, 클라이언트 기반 게임을 가볍고 빠르게 구현하기에 적합하다.

## D02. 조작 방식
- **선택**: 키보드 방향키와 WASD, 화면 방향 버튼
- **근거**: 데스크톱과 모바일 환경을 모두 지원한다.

## D03. 게임 화면
- **선택**: 캐릭터 중심 카메라를 사용하는 2D 탑다운 격자 미로
- **근거**: 이동 및 충돌 로직을 명확하게 유지하면서 후반부의 큰 미로도 읽기 쉽게 표시할 수 있다.

## D04. 전체 단계 수
- **선택**: 순차적으로 진행하는 총 20단계
- **근거**: 초기 10단계 계획을 20단계로 확장했다.

## D05. 구출 대상 수
- **선택**: 1~4단계 1명, 5~8단계 2명, 9~12단계 3명, 13~16단계 4명, 17~20단계 5명
- **근거**: 단계 구간별로 목표 복잡도를 높이고 후반부에는 약 5명을 구출하도록 한다.

## D06. 미로 구조
- **선택**: 모든 칸이 연결되고 두 칸 사이에 하나의 경로만 존재하는 완벽한 미로
- **근거**: 절차적으로 생성되는 랜덤성을 유지하면서도 공정하고 예측 가능한 경로 구조를 제공한다.

## D07. 미로 크기 증가
- **선택**: 1단계 15×15에서 시작해 2단계마다 2칸씩 증가하며 20단계에서 33×33
- **근거**: 초반부터 지나치게 어렵지 않으면서 탐색 난이도를 점진적으로 높인다.

## D08. 미로 생성 시점
- **선택**: 새 단계 시작, 재시작, 재플레이 시 새 미로 생성; 일시정지 후 이어하기에서는 현재 미로 유지
- **근거**: 매번 새로운 맵을 제공하면서도 저장된 게임은 같은 미로에서 이어할 수 있게 한다.

## D09. 제한 시간
- **선택**: 모든 단계에 미로 크기와 구출 대상 수를 기준으로 계산한 제한 시간을 적용하며, 일시정지 중에는 타이머를 멈춤
- **근거**: 단계가 올라갈수록 긴장감을 높이되, 큰 미로와 많은 구출 대상이 있는 단계에는 비례해 더 많은 시간을 제공한다.

## D10. 시간 초과 처리
- **선택**: 같은 미로 재도전 또는 새 미로로 재시작할 수 있는 실패 화면 표시
- **근거**: 연습과 새로운 도전을 모두 지원하면서 공정성을 유지한다.

## D11. 목표 상호작용
- **선택**: 플레이어가 구출 대상 또는 탈출구 칸에 들어가면 자동 상호작용
- **근거**: 조작을 이동에 집중한다. 구출 대상 칸에 도착하면 자동으로 구출되며, 모든 대상을 구출한 뒤 탈출구에 도착해야 단계가 완료된다.

## D12. 구출한 캐릭터의 이동
- **선택**: 구출한 캐릭터가 플레이어 뒤를 일렬로 따라옴
- **근거**: 구출 진행 상황을 화면에서 확인할 수 있고 호송 목표를 명확하게 보여준다.

## D13. 단계 진행
- **선택**: 순차 해금 및 완료 단계 재플레이 허용
- **근거**: 캠페인 진행 구조를 유지하면서 이전 기록을 향상할 수 있게 한다.

## D14. 일시정지와 이어하기
- **선택**: 페이지나 탭으로 돌아오면 자동 일시정지하고 이어하기 버튼 표시
- **근거**: 진행 상황을 보호하고 게임을 보고 있지 않은 동안 타이머가 흐르지 않도록 한다.

## D15. 진행 상황 저장
- **선택**: 현재 단계, 생성된 미로, 플레이어 위치, 구출 상태, 이동 횟수, 타이머 상태, 단계별 최고 기록을 포함한 버전 관리형 `localStorage` 저장 데이터
- **근거**: 새로고침, 탭 복귀, 브라우저 종료 후에도 이어할 수 있으며 향후 계정 동기화를 위한 안정적인 저장 구조를 마련한다.

## D16. 향후 계정 데이터 병합
- **선택**: 로컬과 Microsoft 계정 데이터를 병합할 때 가장 많이 해금된 진행도와 단계별 더 좋은 기록을 유지
- **근거**: 향후 로그인 기능을 추가할 때 의미 있는 진행 상황이나 최고 기록이 사라지는 것을 방지한다.

## D17. 게임 에셋
- **선택**: 캐릭터, 구출 대상, 탈출구, 환경 에셋을 AI로 생성하고 프로젝트 내부에 로컬 파일로 저장
- **근거**: 외부 URL에 런타임으로 의존하지 않으면서 독창적인 그래픽을 제공한다.

## D18. 시각적 방향
- **선택**: 밝고 친근한 판타지 탐험 스타일
- **근거**: 구출 중심의 게임플레이와 어울리고 누구나 쉽게 접근할 수 있는 분위기를 만든다.

## D19. 탐색 보조 기능
- **선택**: 미니맵을 제공하지 않음
- **근거**: 미로 탐색과 기억을 핵심 재미로 유지한다.

## D20. 기록 항목
- **선택**: 단계별 클리어 시간과 이동 횟수 기록
- **근거**: 목숨 시스템이나 영구적인 실패 패널티 없이 재플레이 목표를 제공한다.
