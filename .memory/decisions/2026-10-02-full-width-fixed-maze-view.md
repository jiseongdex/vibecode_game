# Decisions: 가로폭을 채우는 고정 내부 시야

- Date: 2026-10-02
- Status: Confirmed

## D01. 내부 게임 시야
- **Chosen**: 창 크기가 달라져도 맵틀 안에 보이는 가로·세로 타일 수와 플레이어·타일·장애물의 상대 비율을 유지한다. 새 기준은 `1240×840` 내부 화면에 `120px` 타일로 가로 약 `10.3`칸·세로 `7`칸이다. 맵틀과 내부 렌더링을 같은 배율로 확대·축소하고, 카메라의 플레이어 추적과 끝 지점 제한에도 같은 배율을 쓴다.
- **Rationale**: 사용자가 양옆 빈 공간을 없애면서 내부 플레이 시야를 화면 크기와 무관하게 유지하기를 요청했고, 기존 약 `8.9×6`칸보다 조금 더 보이는 `10.3×7`칸을 선택했다. `140px` 타일은 이 결정에서 `120px`로 바꾼다.

## D02. 맵틀 가로폭과 세로 스크롤
- **Chosen**: 맵틀을 플레이 페이지에서 사용할 수 있는 가로폭까지 넓힌다. 창 높이 때문에 배율을 다시 줄이지 않는다. 맵틀 높이는 고정된 외형 비율 `1250:850`에 따라 함께 늘어나며, 창보다 길어지면 **페이지의 세로 스크롤을 허용**한다. 가로 스크롤과 맵틀 내부 스크롤은 만들지 않는다.
- **Rationale**: 사용자가 세로 높이와 가로폭이 충돌할 때 ‘같은 비율로 키우고 세로 페이지 스크롤 허용’을 선택했다. 이는 [이전 결정](./2026-10-01-laptop-wide-maze-mobile-arrows.md)의 ‘창 높이에 맞춰 축소하고 스크롤 없음’ 규칙을 이 요청에 대해 대체한다.

## D03. 페이지 요소와 조작 접근성
- **Chosen**: 단계 선택 화면에서는 `동물 구출 대작전` 제목 영역을 유지하고, 단계를 골라 게임 세션에 들어간 뒤에는 제목 영역 전체를 표시하지 않는다. 이는 준비·플레이·일시정지·결과 상태와 저장된 게임 재개에 모두 적용한다. HUD·시작 버튼·모바일 방향 버튼은 맵틀과 함께 자연스러운 페이지 흐름에 둔다. 넓어진 맵틀 때문에 일시정지·결과 창이 현재 창 밖에 뜨지 않도록 팝업은 보이는 브라우저 영역에서 열리고 조작 가능해야 한다. `600px` 이하에서만 방향 버튼을 표시하는 기존 결정과 키보드 방향키/WASD 입력은 유지한다.
- **Rationale**: 사용자가 단계 선택 후 게임 진입 시 제목 영역 제거를 요청했다. 맵틀이 창보다 높아질 때 현재의 맵틀 기준 절대 위치 팝업은 화면 아래에 나타날 수 있으므로, 게임 상태 전환 조작은 보이는 곳에 있어야 한다.

## D04. 범위와 검증
- **Chosen**: 플레이 화면의 맵틀 크기 계산, 기준 타일 크기, 세로 페이지 레이아웃, 게임 중 제목 숨김과 팝업 배치를 조정한다. 미로 생성, 이동·충돌·구출 규칙, 저장 형식, 이미지 자산, 캠페인의 단계 선택 UI는 변경하지 않는다. 노트북·넓은 데스크톱·모바일에서 제목 표시 상태, 맵틀 양옆 여백, 약 `10.3×7`칸의 보이는 시야, 플레이어 비율, 카메라, 가로/세로 스크롤, HUD·버튼·팝업 접근성을 확인한다.
- **Rationale**: 요청은 게임 규칙이 아닌 플레이 화면의 크기와 표시 방식 변경이다.

## D05. 후속 요청: 더 넓은 타일 시야
- **Chosen**: `1240×840` 내부 화면 크기는 유지하고 기준 타일을 현재 구현의 `108px`에서 `90px`로 줄인다. 가로 약 `13.8`칸·세로 약 `9.3`칸이 보이게 하며, 장면 배율과 카메라·미니맵 시야 표시도 새 타일 크기에 맞춘다.
- **Rationale**: 사용자가 한 화면에 더 많은 맵 칸이 보이도록 게임 시야를 조정해 달라고 요청했다. D01의 `120px`는 이전 결정값이며, 현재 구현의 `108px`를 기준으로 약 20% 더 많은 칸이 보이도록 선택했다.

## D06. 후속 요청: 보이는 칸 수 추가 확대
- **Chosen**: 기준 타일을 `90px`에서 `80px`로 한 단계 더 줄인다. `1240×840` 내부 화면에는 가로 `15.5`칸·세로 `10.5`칸이 보인다. 카메라 추적과 미니맵 시야 테두리도 이 크기에 맞춘다.
- **Rationale**: 사용자가 맵의 보이는 칸을 조금 더 늘려 달라고 요청했다. D05의 `90px`를 현재 기준으로 삼고 약 12.5% 더 많은 칸이 보이도록 한다.
