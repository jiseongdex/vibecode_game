# Decision: 따라오는 동물의 점프 효과 제거

## 확정된 요구

- 사용자는 구출한 동물이 따라올 때 반복되는 통통 튀는 효과가 부자연스럽다고 느꼈다.
- 이전 대화에서 점프 효과를 제거하고 부드러운 위치 이동만 남기는 방안을 추천했고, 사용자가 그대로 수정하도록 요청했다.
- 구출 전 철장, 구출 후 동물의 방향 이미지, 플레이어 이동과 탈출구 연출은 유지한다.

## 코드 확인

- `MazeBoard`가 `followerMoved`를 계산해 `RescueSprite.animateMove`로 보낸다.
- `RescueSprite`는 `hopping` 상태와 220ms 타이머로 `.hopping`을 붙인다.
- `.followerSprite`에는 이미 `top`/`left`의 120ms 선형 전환이 있으므로 점프를 제거해도 따라오는 이동은 부드럽게 이어진다.

## 결정

- 동물 전용 점프 상태·타이머·CSS keyframes·불필요한 이동 판정 전달을 삭제한다.
- 동물의 위치 전환, 방향에 따른 이미지, 새 동료 등장, 철장 표시는 유지한다.
- 관련 테스트를 점프 검증에서 위치 이동과 DOM 요소 유지 검증으로 바꾼다.
