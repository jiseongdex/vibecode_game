# Decisions: 랭킹 고정 순위와 그림 단계 버튼

- Date: 2026-10-08
- Status: Confirmed

## D01. 랭킹 순서와 페이지 이동
- **Chosen**: 기존 서버 순위와 동률 규칙을 유지하고, 기존 10명 단위 페이지네이션을 사용한다. 순위 자료가 10명보다 적으면 해당 페이지의 나머지 자리를 빈 칸으로 채운다. 기록이 0명이어도 첫 페이지의 1~10위 자리를 표시한다.
- **Rationale**: 사용자가 1~10위 상시 표시와 초과 기록의 스크롤 또는 페이지네이션을 요청했고, 이전 대화에서 페이지네이션을 선택했다. 서버는 최고 단계·최단 시간과 공동 순위를 이미 계산한다.

## D02. 내 기록의 상단 고정
- **Chosen**: 랭킹 제목 바로 아래에 `내 기록` 영역을 항상 표시한다. `current`가 있으면 실제 순위·이름·단계·시간을 표시하고, 없으면 로그인 계정의 표시 이름과 `순위 없음`·`기록 없음`을 표시한다. 아래 10개 순위 목록에는 내 순위가 포함되면 그대로 표시한다.
- **Rationale**: API의 `LeaderboardDto.current`는 완료 기록이 없으면 `null`이며, 상위 100명 밖이어도 내 순위를 따로 준다. 항상 보이는 자기 기록을 위해 계정 표시 이름을 `App`에서 전달한다.

## D03. 빈 순위 칸
- **Chosen**: 빈 칸은 순위 숫자만 보이고 닉네임·단계·시간은 비운다. 스크린 리더에는 해당 칸이 기록 없음으로 전달한다. 목록의 실제 항목은 서버 응답 순서를 바꾸지 않고 공동 순위를 그대로 표시한다.
- **Rationale**: 사용자 요청의 빈 닉네임 칸을 지키면서도 빈 행을 데이터로 오해하지 않게 한다. 화면 전용 칸이므로 API·DB를 변경하지 않는다.

## D04. 단계 버튼 그림과 잠금 상태
- **Chosen**: 기존 버섯·발자국·나뭇잎 `StickerIcon` SVG를 버튼의 큰 그림으로 사용하고 그 위에 `N단계` 글자만 겹친다. 사각형 배경·테두리와 `시작하기`·`잠김`·`최고 시간` 보조 문구는 단계 버튼에서 제거한다. 잠긴 단계는 기존 `disabled` 동작과 접근 가능한 `aria-label`을 유지하고 그림을 회색으로 표시한다.
- **Rationale**: 사용자가 그림 위 단계 글자만 있는 버튼과 회색 비활성 그림을 요청했다. 단계 해금과 최고 기록 데이터는 그대로 유지한다.

## D05. 범위와 검증
- **Chosen**: 랭킹 표시 컴포넌트·계정 이름 전달 경로·단계 버튼 스타일과 관련 테스트를 수정한다. 서버 랭킹 계산, 모바일 탭, 배포 설정은 변경하지 않는다. 1440×900, 낮은 데스크톱, 320px 화면을 확인한다.
- **Rationale**: 이전 화면 요구와 진행 중인 배포 작업을 보존한다.
