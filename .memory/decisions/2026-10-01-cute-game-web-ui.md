# Decisions: 동물 구출 대작전 웹 UI

- Date: 2026-10-01
- Status: Confirmed

## D01. 전체 디자인 콘셉트
- **Chosen**: 숲속 동화책과 탐험 수첩의 따뜻한 분위기를 바탕으로, 귀엽고 부드러운 스티커 느낌을 더한다. 크림색 종이 바탕, 민트색, 작은 코랄·딸기색 포인트를 사용한다.
- **Rationale**: 게임의 미로 탐험 분위기와 현재의 숲·사탕·얼음·사막 테마를 함께 담을 수 있는 포근한 기반을 만든다.

## D02. 게임 제목과 부제
- **Chosen**: 게임 제목은 `동물 구출 대작전`, 부제는 `알록달록한 미로를 지나 친구들을 구해요`로 한다.
- **Rationale**: 제목은 바이옴과 상관없이 구출 목표를 바로 전달하고, 부제는 여러 테마의 미로 탐험을 함께 보여 준다.

## D03. 글꼴
- **Chosen**: Nanum Pen Script를 UI 전체 글꼴로 프로젝트에 포함해 오프라인에서도 쓴다. 공개 SIL Open Font License 글꼴 파일과 라이선스 고지를 함께 보관한다. 글꼴의 개성은 유지하되 충분한 글자 크기·줄 간격·색 대비를 적용한다.
- **Rationale**: 사용자가 동화책 느낌을 위해 손글씨 글꼴 하나로 통일하는 안을 선택했다. 글꼴 메타데이터는 Nanum Pen Script, Korean subset, Regular TTF 파일, OFL 라이선스를 표시한다.

## D04. 변경 범위
- **Chosen**: 상단 제목, 단계 선택 페이지, 플레이 HUD, 방향 조작 버튼, 일시정지·결과 창 등 앱의 웹 UI 전반을 다듬는다. 미로 타일 이미지, 플레이어·동물 이미지, 게임 규칙과 저장 형식은 유지한다.
- **Rationale**: 게임 바깥 웹 UI와 게임 중 조작 UI를 같은 콘셉트로 연결하면서 기존 플레이 자산과 기능을 보호한다.

## D05. 문구
- **Chosen**: 안내 문구는 따뜻하고 쉬운 모험 말투로 다듬고, 버튼과 기능명은 의미를 바로 알 수 있게 유지한다. 캠페인 화면에 부제 `알록달록한 미로를 지나 친구들을 구해요`를 표시한다.
- **Rationale**: 동화 분위기는 더하되 플레이어가 조작과 상태를 헷갈리지 않게 한다.

## D06. 버튼과 장식
- **Chosen**: 단계와 주요 동작은 말랑한 캡슐형 스티커 버튼·카드로 표현하고, 작은 잎·버섯·발자국 SVG 장식을 프로젝트 안에 둔다. 기본 버튼 상태, 호버·눌림 상태, 비활성·완료·해금 상태를 구별한다. 외부 장식 이미지나 런타임 웹 폰트 요청은 추가하지 않는다.
- **Rationale**: 스티커 같은 시각 언어와 기기 간 일관성을 살리고, 새 이미지를 별도 생성하지 않아도 가벼운 인터페이스를 만들 수 있다.

## D07. 단계 선택 지도
- **Chosen**: 기존 20단계 기능을 5×4 지그재그 탐험 경로로 재구성한다. 넓은 화면에서는 한눈에 보고, 작은 화면에서는 두 단계씩 배치한다. 완료·현재 해금·잠김 상태를 유지하며 키보드 포커스와 터치 영역을 식별 가능하게 둔다.
- **Rationale**: 기존 단계 카드 격자보다 탐험하는 느낌을 주고, 20단계 전체 구조를 계속 빠르게 훑어볼 수 있다.

## D08. 바이옴 표현과 단계 데이터
- **Chosen**: 단계 경로는 특정 단계와 숲·사탕·얼음·사막 테마를 고정 연결하지 않는 보편적인 모험 지도로 그린다. UI 장식에는 여러 바이옴을 떠올릴 수 있는 작은 SVG 포인트를 쓸 수 있지만, 실제 단계 테마 선택은 그대로 둔다.
- **Rationale**: `getMazeTheme(seed)`가 미로 시드에 따라 테마를 무작위 선택하므로 캠페인 지도에서 단계별 바이옴을 고정하면 실제 플레이 테마와 어긋날 수 있다.
