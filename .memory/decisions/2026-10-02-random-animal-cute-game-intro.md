# Decisions: 새 미로 동물 랜덤 선택·안내 폰트·시작 연출

- Date: 2026-10-02
- Status: Confirmed

## D01. 새 미로의 동물 배정

- **Chosen**: 새 게임마다 구출 대상의 동물을 다시 무작위로 배정한다. 기존 5종(토끼, 여우, 곰, 흰 고양이, 강아지)에서 그 단계의 구출 대상 수(1~5마리)만큼 **중복 없이** 선택한다.
- **Rationale**: 사용자가 매번 새 게임에서 동물이 바뀌길 원했고, 여러 마리가 있는 단계에서는 각 동물을 다르게 배정하기로 선택했다.
- **Code basis**: `getRescueCount()`가 단계별 1~5마리를 정하고, `getRescueAnimal()`은 현재 `rescue-1`~`rescue-5`를 고정 동물에 연결한다. 새 게임에서 ID 배정을 섞으면 기존 표시·저장 구조를 유지할 수 있다.
- **Behavior**: 같은 미로 재도전은 동물 배정도 유지한다. 새 미로 재시작과 단계 선택, 다음 단계 진입은 새로운 배정을 만든다. 저장된 게임을 복원해도 동물 배정은 유지한다.

## D02. 문구와 알림 폰트

- **Chosen**: 한글을 지원하는 **주아(Jua)**를 안내 문구, 상태 알림, 시작 카운트다운에 적용한다. 일반 UI와 버튼의 기존 글꼴은 유지한다.
- **Rationale**: 사용자가 둥글고 선명한 스타일 및 적용 범위를 선택했다.
- **Code basis**: 현재 UI 글꼴은 `Nanum Pen Script` 하나이며 `src/styles/tokens.css`의 `--font-ui`와 `src/styles/global.css`의 `@font-face`로 관리한다. 주아는 기존 글꼴과 함께 로컬 웹폰트로 제공하고 로딩 실패 시 기본 글꼴로 대체한다.
- **Source**: https://github.com/google/fonts/tree/main/ofl/jua (글꼴 및 OFL 라이선스)

## D03. 단계 진입 시 자동 시작 연출

- **Chosen**: 단계 선택이나 다음 단계로 게임에 진입하면 기존 게임 화면의 `시작하기` 버튼 대신 미로 틀 안에 반투명 어둡게 처리한 미로를 보여준다. 그 위에 `동물을 구출해서 탈출해줘!`를 약 3초 표시하고 `3 → 2 → 1`을 약 1초씩 표시한 뒤 자동으로 게임을 시작한다.
- **Rationale**: 사용자가 요청한 안내 순서와 자동 시작 흐름이다.
- **Behavior**: 연출이 끝날 때까지 이동 입력과 게임 타이머는 시작하지 않는다. 카운트다운 종료 시 오버레이를 제거하고 게임 상태를 `playing`으로 바꾼다. 오버레이는 미로 틀 내부에만 표시한다.
- **Code basis**: 현재 `GameScreen`은 `ready` 상태에서 `시작하기` 버튼을 누르면 `START`를 dispatch한다. `START`가 타이머 시작 시각을 정하고 `playing`일 때만 이동과 1초 타이머가 작동한다.

## D04. 재도전과 저장 게임 복원

- **Chosen**: 결과 화면의 `같은 미로 재도전`과 `새 미로로 재시작/재플레이`는 안내 문구를 생략하고 `3 → 2 → 1`만 약 1초씩 보여준 뒤 자동으로 게임을 시작한다. 저장된 게임의 복원은 기존처럼 일시 정지 화면에서 사용자가 이어서 시작한다.
- **Rationale**: 사용자가 재도전에는 카운트다운만 보여주도록 정정했다. 복원 시에는 기존 일시 정지 동작을 유지한다.
- **Behavior**: 재도전 카운트다운 동안 이동 입력과 게임 타이머는 시작하지 않는다. 카운트다운 종료 시 `START`를 적용한다.
- **Code basis**: 현재 `RETRY_SAME_MAZE`와 `RESTART_NEW_MAZE`는 둘 다 `ready` 상태를 반환한다. 구현 시 진입 경로를 구분해야 한다.

## D05. 일시 정지 버튼

- **Chosen**: HUD의 `일시정지` 버튼 표시 문구를 `잠깐 쉬기`로 바꾼다. 일시 정지 기능 자체는 유지한다.
- **Rationale**: 사용자가 요청한 문구다.
- **Code basis**: `src/components/Hud/GameHud.tsx`의 버튼이 현재 `일시정지`를 표시한다.

## 범위와 확인 사항

- 사용자 확정: 동물 재추첨 시점, 중복 없는 여러 동물, 주아 폰트 및 적용 범위, 재도전의 카운트다운만 표시.
- 코드에서 확인: 5종 동물, 단계당 1~5마리, `ready`/`playing` 상태, 시작 버튼, 재도전 경로, 저장 게임 복원, 기존 글꼴 및 HUD 버튼.
- 이 결정 파일은 인터뷰 결과다. 구현과 테스트는 `/memory-plan` 후 `/memory-execute` 단계에서 진행한다.
