# Plan: 동물 랜덤 배정·귀여운 안내 폰트·자동 시작 연출

## Goal

새 게임마다 기존 5종 중 단계에 필요한 1~5마리를 중복 없이 배정하고, 안내·알림에는 주아(Jua) 폰트를 사용한다. 단계 진입은 3초 안내 문구와 3·2·1 후 자동 시작하며, 같은/새 미로 재도전은 3·2·1만 보여준다. 카운트다운 전에는 이동과 게임 시간이 진행되지 않고 일시 정지 버튼은 `잠깐 쉬기`로 표시된다.

## Source Decisions

- [확정 결정](../decisions/2026-10-02-random-animal-cute-game-intro.md)
- 기존 완료 계획은 유지한다. 현재 포인터는 완료된 미니맵 계획에서 아래 P01-T01로 전진한다.

## Phases

| Phase | Status | Summary | Blueprint |
| :--- | :--- | :--- | :--- |
| P01 | `done` | 동물 배정, 문구 스타일, 시작 흐름을 독립 검증 가능한 세 Task로 구현 | [P01](../phases/2026-10-02-random-animal-cute-game-intro/P01-game-entry/phase.md) |

## Sequence

1. T01: 미로 시드로 5종 ID를 섞어 구출 대상에 중복 없이 배정한다. 같은 미로 재도전과 저장 복원은 동물 정체성을 유지한다.
2. T02: 주아 글꼴을 로컬 자산으로 추가하고 안내·알림만 적용한다. HUD 버튼은 `잠깐 쉬기`로 바꾼다.
3. T03: 진입 경로에 따라 3초 안내+카운트다운 또는 카운트다운만 표시하고 자동으로 `START`한다. 게임·앱 통합 테스트를 갱신한다.

## Completion Gate

- 각 Task의 지정 테스트와 `npm.cmd run build`가 통과한다.
- 시작 전 입력/타이머 정지, 재도전 카운트다운, 저장 게임의 일시 정지 복원, 모바일·낮은 가로 화면의 문구 가독성을 확인한다.
