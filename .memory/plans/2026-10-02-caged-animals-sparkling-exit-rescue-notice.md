# Plan: 구출 전 철장·반짝이는 탈출구·구출 완료 안내

## Goal

미구출 동물 위에 투명 철장 자산을 겹쳐 갇힌 상태를 보여준다. 탈출구 문은 플레이어와 같은 크기·행 깊이로 장애물 사이에 자연스럽게 놓고, 모든 동물 구출 후 금빛 별빛을 표시한다. 마지막 동물 구출 순간 미로 위쪽 중앙에 1.5초 비차단 알림을 보여준다. 단계 선택의 두 설명 문구를 줄이고 첫 문구 오타를 고친다.

## Source Decisions

- [확정 결정](../decisions/2026-10-02-caged-animals-sparkling-exit-rescue-notice.md)
- `src/App.tsx`와 `src/components/Campaign/CampaignScreen.tsx`의 문구는 이미 커밋되지 않은 사용자 변경이다. 해당 파일을 건드리는 T03에서 수정 범위를 제한하고, T01·T02 커밋에는 포함하지 않는다.

## Sequence

1. T01: 투명 철장·별빛 PNG를 생성해 프로젝트에 저장하고, 미구출 동물과 열린 탈출구에 각각 겹친다. 문을 플레이어 크기·행 깊이로 배치해 앞쪽 장애물이 자연스럽게 가리도록 한다. 잠긴 문·구출 후 동료에는 효과를 표시하지 않는다.
2. T02: 마지막 동물 구출 전이만 감지해 미로 위쪽 중앙에 1500ms 비차단 알림을 표시하고 종료·복원 경로를 검증한다.
3. T03: 두 안내 문구 크기를 각각 줄이고 첫 문구의 `떠자나!`를 `떠나자!`로 고친다. 기존 미커밋 문구 변경을 보존한다.

## Completion Gate

- 투명 자산 두 개가 프로젝트에 존재하고, 미구출/구출 후·잠김/열림 상태별 표시가 맞으며 기존 동물·문 원본은 유지된다. 문은 `1.6 × cellSize`이고 플레이어와 같은 행 깊이로 앞쪽 장애물 뒤에 놓인다.
- 구출 알림은 마지막 동물 때만 한 번 1.5초 나타나고, 이동과 시간은 멈추지 않으며 저장 복원 때 다시 나타나지 않는다.
- 요청된 두 문구만 작아지고 첫 문구 오타가 수정된다. 단계 카드와 진행률 글자 크기는 그대로다.
- 각 Task의 지정 테스트·전체 테스트·빌드가 통과한다. 브라우저 연결 시 작은 미로 셀, 모바일, 낮은 가로 화면의 가독성과 이미지 겹침을 육안 확인한다.
