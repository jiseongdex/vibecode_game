# Plan: 창 크기와 무관한 고정 게임 시야

## Goal

[고정 게임 시야 결정](../decisions/2026-10-01-fixed-maze-view.md)에 따라 실제 미로가 보이는 내부 영역을 `1240×840px`로 고정한다. 창을 조절해도 시각 격자 크기, 플레이어 표시 크기, 카메라 시야가 바뀌지 않아야 한다. 작은 창에서는 페이지 스크롤로 전체 게임틀에 접근한다.

## Phases

| Phase | Status | Summary | Blueprint |
| :--- | :--- | :--- | :--- |
| P01 | `done ✅` | 고정 보드 기하, 외부 스크롤 배치, 카메라·오버레이 회귀 검증 | [P01](../phases/2026-10-01-fixed-maze-view/P01-fixed-viewport/phase.md) |

## Task Order

1. T01에서 보드 측정을 제거하고 고정 내부 시야를 적용한다. 게임틀과 오버레이를 그 크기에 맞추고, 좁은 화면의 스크롤과 카메라를 검증한다.

## Boundaries

- `gameReducer`, 미로 생성, 저장 스키마, 이미지 자산, 이동·충돌·구출 동작은 변경하지 않는다.
- 게임 바깥 제목·HUD·방향 버튼의 기존 반응형 배치는 유지한다.
- `2026-10-01-zoomed-maze-viewport.md`의 창 크기에 따른 타일 재계산은 이번 결정으로 대체한다.
