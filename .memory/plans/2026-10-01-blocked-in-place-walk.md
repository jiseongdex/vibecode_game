# Plan: 장애물 앞 제자리 걸음

## Goal

[결정 문서](../decisions/2026-10-01-blocked-in-place-walk.md)에 따라 플레이어가 위·왼쪽·아래·오른쪽 장애물에 막혀도 이동 입력 동안 해당 방향 걷기 이미지가 반복되게 한다. 좌표·충돌·카메라·동물 동작은 유지하고, 키 해제·포커스 상실·플레이 중단 시 제자리 걸음을 정지한다.

## Phases

| Phase | Status | Summary | Blueprint |
| :--- | :--- | :--- | :--- |
| P01 | `done ✅` | 키 유지 신호와 막힌 이동의 걷기 표시를 연결하고 회귀 검증 | [P01](../phases/2026-10-01-blocked-in-place-walk/P01-blocked-walk/phase.md) |

## Task Order

1. T01에서 키보드 유지 방향을 화면에 전달하고, 막힌 이동 시 기존 걷기 프레임을 재생하며 관련 테스트를 갱신한다.

## Boundaries

- 기존 110ms 키 반복과 55ms/110ms 걷기 프레임 타이밍을 그대로 쓴다.
- `gameReducer`의 이동·충돌·저장 스키마, 이미지 파일, 동물 애니메이션은 변경하지 않는다.
- 기존 `2026-10-01-blocked-player-size.md`의 막힌 이동에서 기본 이미지만 보이는 규칙은 이번 결정으로 대체한다. 플레이어 DOM과 표시 상자 크기는 고정한다.
