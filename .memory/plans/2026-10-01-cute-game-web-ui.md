# Plan: 동물 구출 대작전 웹 UI

## Goal

확정된 [웹 UI 결정](../decisions/2026-10-01-cute-game-web-ui.md)에 따라 앱 전체를 크림·민트·딸기색의 동화책/탐험 수첩 분위기로 바꾼다. 오프라인에서 같은 손글씨 글꼴을 쓰고, 20개 단계가 반응형 지그재그 탐험 경로로 보이며, 플레이 중 HUD·조작·팝업이 같은 시각 언어를 공유한다. 미로 타일, 캐릭터/동물 이미지, 게임 및 저장 규칙은 유지한다.

## Phases

| Phase | Status | Summary | Blueprint |
| :--- | :--- | :--- | :--- |
| P01 | `done ✅` | 공통 정체성, 단계 경로, 플레이 화면 웹 UI | [P01](../phases/2026-10-01-cute-game-web-ui/P01-storybook-ui/phase.md) |

## Boundaries

- 결정된 제목: `동물 구출 대작전`; 부제: `알록달록한 미로를 지나 친구들을 구해요`.
- Nanum Pen Script Regular TTF와 OFL 라이선스를 프로젝트에 포함한다. 웹 폰트 런타임 요청이나 새 패키지는 없다.
- 단계 경로는 실제 미로의 얼음/사탕/사막/숲 테마와 연결하지 않는다. 실제 테마는 시드로 정해진다.
- 장식은 접근성 이름을 만들지 않는 코드 기반 SVG로 구현한다. 단계·버튼의 의미는 글과 상태로도 드러나야 한다.

## Task Order

1. T01에서 글꼴·공통 토큰·앱 제목·공유 장식을 마련한다.
2. T02에서 공통 자산을 이용해 단계 선택과 탐험가 선택을 반응형 숲길로 바꾼다.
3. T03에서 플레이 화면 주변 UI와 팝업에 같은 디자인을 적용하고 전체 화면을 점검한다.
