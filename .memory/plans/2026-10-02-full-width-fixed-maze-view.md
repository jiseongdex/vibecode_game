# Plan: 가로폭을 채우는 고정 내부 시야

## Goal

[확정된 결정](../decisions/2026-10-02-full-width-fixed-maze-view.md)에 따라 게임 진입 후 제목 영역을 없애고 맵틀을 페이지의 사용 가능한 가로폭까지 넓힌다. 새 기준 시야는 `1240×840` 안의 약 `10.3×7`칸이며 모든 창에서 고정한다. 맵틀 높이는 같은 비율로 늘리고 세로 페이지 스크롤을 허용한다. 일시정지·결과 팝업은 보이는 창에서 조작할 수 있게 한다.

## Phases

| Phase | Status | Summary | Blueprint |
| :--- | :--- | :--- | :--- |
| P01 | `done ✅` | 게임 세션 제목·페이지 흐름·가로폭 배율·120px 타일 시야·팝업 및 회귀 검증 | [P01](../phases/2026-10-02-full-width-fixed-maze-view/P01-full-width-scene/phase.md) |

## Task Order

1. T01에서 세션 전용 제목 제거, 너비 기준 맵틀 배율, 페이지 세로 흐름, 고정된 `120px` 기준 타일·카메라, 팝업 배치와 테스트를 함께 구현한다.

## Boundaries

- 맵틀 outer 기준 `1250×850`, 내부 viewport 기준 `1240×840`은 동일 비율 확대의 기준이다. 모든 화면에서 tile baseline `120px`을 사용해 가로 약 `10.33`칸·세로 `7`칸을 보이게 한다.
- 창 높이는 맵틀 배율을 제한하지 않는다. 맵틀 내부와 문서의 가로 스크롤은 없고, 필요한 문서 세로 스크롤만 허용한다.
- 캠페인 제목·단계 목록, 미로 생성·이동·충돌·구출, 저장 스키마, 이미지와 `600px` 이하 전용 방향 버튼은 유지한다.
