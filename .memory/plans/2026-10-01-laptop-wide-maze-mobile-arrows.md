# Plan: 노트북 가로폭에 맞춘 맵틀과 작은 화면 전용 방향 버튼

## Goal

[확정된 결정](../decisions/2026-10-01-laptop-wide-maze-mobile-arrows.md)에 따라 플레이 맵의 보이는 칸 수와 비율을 유지하면서 노트북·PC 화면에서 사용 가능한 가로폭을 최대한 쓴다. 창 높이가 모자라면 높이에 맞춰 줄여 문서 스크롤을 만들지 않는다. 키보드 모양의 방향 버튼은 너비 `600px` 이하에서만 표시한다.

## Phases

| Phase | Status | Summary | Blueprint |
| :--- | :--- | :--- | :--- |
| P01 | `done ✅` | 게임틀 확대 제한과 PC 버튼 공간을 제거하고 모바일 방향키 및 레이아웃을 검증 | [P01](../phases/2026-10-01-laptop-wide-maze-mobile-arrows/P01-wide-playfield/phase.md) |

## Task Order

1. T01에서 게임틀 배율·폭과 방향 버튼 표시/공간 예약을 함께 변경하고 브라우저 화면 크기별 회귀 검증을 끝낸다.

## Boundaries

- `1240×840` 내부 시야, `1250×850` 외부 틀과 `140px` 기준 타일의 상대 비율을 유지한다. 확대 시 세 값을 동일 배율로 변경한다.
- 노트북에서 가로폭을 채우기 위해 세로 스크롤을 도입하거나 보이는 맵 위아래를 자르지 않는다. 높이가 제한하면 좌우 여백을 허용한다.
- 게임 규칙, 저장 스키마, 이동 키 처리, 이미지, 캠페인 화면은 변경하지 않는다.
