# 계획: 렌더 칸 단위 이동

## 목표
현재 2N+1 렌더 격자의 인접 칸 하나를 게임 이동 한 칸으로 사용한다. 열린 통로 연결 칸만 통과할 수 있고, 벽 장애물과 교차점 장식 칸은 막힌다. 바닥 칸 중심 사이에는 두 번의 입력이 필요하다. 출구와 구조 대상은 바닥 중심에 두며, 동행 동물은 매 단계 이전 플레이어 위치를 따라온다. 위치 세이브를 v4로 올리고 v3 세이브는 마이그레이션하지 않는다. 제한 시간은 그대로 두고 실제 플레이 후 조정한다.

## 완료 기준
- 방향 입력 한 번마다 확장 렌더 격자 좌표가 최대 한 칸 바뀐다.
- 열린 통로 연결 칸에 진입하고 그 칸에서 정지할 수 있다. 벽 연결 칸, 교차점 장식 칸, 보드 경계는 좌표를 바꾸지 않는다.
- 바닥 중심에서 인접 바닥 중심까지 두 입력이 필요하며, 원래의 미로 연결 위상은 유지된다.
- 출구와 구조 대상은 홀수 행·홀수 열의 기존 바닥 중심에 남는다. 구조 후 동행 동물은 각 이동에서 이전 좌표를 한 칸씩 따른다.
- v4 세이브는 중간 통로 칸 위치를 저장·복구한다. v3 위치 세이브는 복원하지 않는다.
- 출구 이미지의 알파 투명도를 유지하고 컨테이너의 불투명 배경색을 사용하지 않는다.
- 기존 스프라이트 크기, 스테이지 제한 시간, 시간 기록 전용 진행 기록을 유지한다.

## 결정 사항
[확정 결정](../decisions/2026-09-30-one-render-cell-per-move.md)을 따른다. 열린 연결 칸은 이동 가능하고 벽 및 교차점은 막힌다. 출구와 구조 대상은 바닥 중심에 남고 동행 동물은 매 입력 단계마다 한 칸씩 따라온다. 제한 시간은 플레이 후 조정하며 출구 이미지 투명 배경을 보존한다.
