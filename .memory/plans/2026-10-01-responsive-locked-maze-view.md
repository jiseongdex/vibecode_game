# Plan: 반응형 화면틀 안의 일정한 게임 시야

## Goal

[정정된 결정](../decisions/2026-10-01-responsive-locked-maze-view.md)에 따라 게임틀과 페이지는 화면에 맞춰 줄이면서, 내부에 보이는 맵 칸 수와 플레이어·타일 비율을 유지한다. 일반적인 데스크톱·모바일 세로·낮은 가로 창에서 가로·세로 스크롤 없이 HUD, 게임틀, 조작 버튼과 결과 창에 접근할 수 있어야 한다. 이전 [고정 픽셀 구현](../decisions/2026-10-01-fixed-maze-view.md)을 바로잡는다.

## Phases

| Phase | Status | Summary | Blueprint |
| :--- | :--- | :--- | :--- |
| P01 | `done ✅` | 동일 배율의 보드·카메라와 창에 맞는 플레이 UI 배치, 회귀 검증 | [P01](../phases/2026-10-01-responsive-locked-maze-view/P01-responsive-scene/phase.md) |

## Task Order

1. T01에서 남는 공간 기반 배율, 보드와 카메라 크기, 플레이 화면의 반응형 배치, 오버레이 및 테스트를 함께 적용한다.

## Boundaries

- `1240×840px`은 기준 내부 시야다. CSS 화면틀의 최소 너비나 고정 실제 크기로 사용하지 않는다.
- 게임 상태, 이동·충돌·구출 규칙, 저장 형식, 이미지 파일, 기존 걷기 및 모션 감소 동작은 변경하지 않는다.
- 캠페인 화면의 단계 경로 및 스크롤 동작은 유지한다. 플레이 세션의 화면 레이아웃에만 화면 높이 맞춤을 적용한다.
