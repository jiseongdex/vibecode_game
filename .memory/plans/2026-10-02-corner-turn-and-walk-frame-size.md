# Plan: 좁은 길 방향 전환과 걷기 이미지 크기 안정화

## Goal

현재 한 칸 이동과 110ms 키 반복 속도를 유지하면서, 두 방향키로 좁은 사이길을 꺾을 때 한 칸 앞 입구에서 회전한다. 남녀 캐릭터 네 방향의 걷기 A/B PNG 16개는 제자리 걷기 중 기본 이미지와 같은 보이는 높이·발 기준선을 유지한다.

## Completion Criteria

- 방향키/WASD를 겹쳐 눌러도 매 이동 틱에 방향은 하나만 선택한다. 현재 칸 또는 한 칸 앞 입구에서는 새 방향을 우선하고 더 먼 입구로 회전을 예약하지 않는다.
- 키 해제·포커스 상실·일시정지에서 예약과 반복 입력이 정리된다. 기존 이동 속도, 벽 판정, 제자리 걷기와 버튼 한 번 이동은 유지된다.
- 남녀 걷기 PNG 16개의 1254×1254 투명 캔버스, 캐릭터 디자인과 걷기 자세를 유지하면서 기본 이미지 대비 보이는 높이·발 기준선 차이를 검증한다.
- 지정 테스트, 전체 테스트, 빌드를 통과하고 직접 이미지와 가능한 경우 게임 화면에서 크기 출렁임을 확인한다.
