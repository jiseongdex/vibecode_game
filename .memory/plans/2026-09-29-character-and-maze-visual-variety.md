# Plan: 캐릭터·미로 그래픽 다양화

## Goal
기존 대표 이미지 7종을 바탕으로 게임용 4방향 중립 스프라이트 28장과 탐험가 발 교대 프레임 16장을 제작한다. 이후 원본 대표 이미지는 삭제하고 정면 스프라이트를 선택 화면과 동물 기본 표시에 사용한다. 숲·사탕·얼음·사막 테마의 바닥과 입체 장애물 이미지를 미로 seed에 따라 안정적으로 표시한다. 플레이어와 팔로워의 실제 방향을 게임·저장 상태에 연결하고 기존 v1 저장 데이터를 보존한다.

## Completion Criteria
- 탐험가 2종과 구조 동물 5종에 각각 정면·뒷모습·왼쪽·오른쪽의 별도 로컬 이미지가 있고, 탐험가에게는 방향마다 두 가지 발 교대 프레임이 더 있다.
- 벽 입력만 해도 플레이어 시선이 바뀌고, 팔로워는 각자의 실제 이동 방향을 본다. 여자·남자 플레이어의 성공한 이동에는 왼발/오른발 앞 프레임이 교대하고, 실제로 움직인 팔로워에게는 작은 점프 효과가 있다. 정지·막힌 입력·모션 감소 설정에서는 재생하지 않는다.
- 새 미로 생성 시 네 테마 중 하나가 선택되며 같은 미로의 재도전·이어하기에서 같은 테마와 타일 변형이 유지된다.
- 바닥은 테마당 2종, 경계 장식용 장애물은 테마당 3종씩 사용한다. 기존 미로의 통로·충돌·카메라 동작은 유지한다.
- v1 저장 데이터의 진행도·기록·현재 미로·타이머·구조 상태가 v2로 이행된다.
- 각 Task의 명시된 검증을 통과하고 PC·모바일에서 벽, 캐릭터, 탈출구가 구분된다.

## Sequence
T01 탐험가 중립 방향 이미지(완료) → T01A 탐험가 발 교대 프레임 → T02 구조 동물 이미지 → T03 맵 테마 이미지 → T04 방향 상태·저장 마이그레이션 → T05 에셋 연결·보드 표시와 이동 효과. 에셋 Task들이 필요한 로컬 이미지를 완성하고, T04는 저장 가능한 방향 상태를 완성한다. T05는 탐험가의 발 교대 프레임과 동물의 CSS 점프를 연결한다.
